# DeepSeek 代码块跳转 使用手册

## 简介

本用户脚本为 [DeepSeek 聊天页面](https://chat.deepseek.com/) 增加快速跳转功能，在 **代码块** 和 **“已思考”内容区域** 的标题栏添加“开头”和“结尾”两个按钮。点击后页面平滑滚动，使对应的代码块或思考内容快速定位到视口顶部或底部，方便阅读长内容。

## 功能特性

- **自动识别**：自动为页面中所有代码块（`.md-code-block`）和思考内容（`.ds-think-content`）添加按钮，包括动态加载的新消息。
- **样式统一**：按钮完全复用网站原生 `ds-button` 系列样式，与“复制/下载”按钮外观一致，并带有文字标签。
- **响应式设计**：当窗口宽度较小时，按钮文字自动隐藏，仅保留图标，避免拥挤。
- **位置精准**：
  - **代码块**：按钮插入在复制/下载按钮的左侧（保持原有顺序）。
  - **思考部分**：按钮追加在标题栏最右侧（折叠箭头之后）。
- **平滑滚动**：使用 `scrollIntoView({ behavior: 'smooth' })` 实现平滑滚动体验。
- **防重复**：每个代码块或思考区域只添加一次按钮，避免脚本重复执行导致叠加。
- **开源协议**：MIT 许可证，可自由使用、修改和分发。

## 安装方法

### 1. 安装用户脚本管理器

推荐使用 [Tampermonkey](https://www.tampermonkey.net/)（支持 Chrome、Edge、Firefox、Safari 等浏览器）。其他管理器如 Violentmonkey、Greasemonkey 也可使用。

### 2. 安装本脚本

- **方法一：从 Greasy Fork 安装（推荐）**  
  访问脚本发布页（例如：`https://greasyfork.org/zh-CN/scripts/593932`），点击“安装此脚本”即可。

- **方法二：手动安装**  
  1. 打开 Tampermonkey 扩展，点击图标，选择“创建新脚本”。  
  2. 删除默认内容，将完整的脚本代码粘贴进去。  
  3. 按 `Ctrl + S` 保存（或点击“文件”→“保存”）。  
  4. 刷新 DeepSeek 聊天页面即可生效。

## 使用说明

1. 打开 [DeepSeek 聊天页面](https://chat.deepseek.com/) 并开始或打开一个对话。
2. 当回答中出现 **代码块** 或展开 **“已思考”内容** 时，相应标题栏会自动出现两个新按钮：
   - **“开头”按钮**：图标为向上尖角（旋转 180°），点击后页面平滑滚动，使该代码块/思考内容顶部对齐到视口顶部。
   - **“结尾”按钮**：图标为向下尖角（原始方向），点击后页面平滑滚动，使该代码块/思考内容底部对齐到视口底部。
3. 若窗口宽度较窄，按钮文字自动隐藏，仅显示图标；将鼠标悬停在按钮上可看到完整提示（如“跳到代码块开头”）。

## 常见问题

### 1. 按钮没有出现
- 确认已正确安装 Tampermonkey，并启用本脚本。
- 检查脚本是否在 `https://chat.deepseek.com/*` 下运行（Tampermonkey 菜单中脚本是否已启用）。
- 刷新页面，等待内容完全加载。若使用虚拟列表，滚动加载新消息后按钮会自动添加。
- 查看控制台（F12）是否有报错信息，如有请反馈。

### 2. 点击按钮后没有滚动
- 确认浏览器支持 `scrollIntoView` 的 `smooth` 行为（现代浏览器均支持）。
- 尝试在控制台手动执行 `document.querySelector('.md-code-block').scrollIntoView({behavior:'smooth', block:'start'})`，看是否正常。
- 检查脚本是否被其他插件冲突。

### 3. 按钮位置或样式异常
- 网站可能更新了页面结构，导致选择器失效。请更新脚本到最新版本，或反馈问题。

### 4. 如何卸载脚本？
在 Tampermonkey 中，点击扩展图标 → “管理面板”，找到本脚本，点击删除即可。
