# 哔哩哔哩主页 IP 属地 + 评论区一键查主页IP

## 📖 简介

本脚本基于 [maxchang3](https://github.com/maxchang3) 的 `哔哩哔哩主页 IP 属地`（0.0.5 版）扩展改进，在保留原「个人主页显示 IP 属地」功能的基础上，新增了 **评论区一键查询用户主页 IP 属地** 的功能，让你在浏览评论区时，无需跳转即可快速查看任意用户（包括楼中楼回复）的个人主页 IP 属地。

---

## ✨ 功能特性

- **个人主页 IP 显示**：浏览任意用户个人主页时，在用户名旁自动显示其 IP 属地（与官方 App 数据一致）。
- **评论区一键查询**：每条评论的“IP属地：XX”后方会出现一个 **“获取”** 按钮，点击即可显示该用户个人主页的 IP 属地。
- **支持楼中楼（回复）**：评论区的主评论和所有回复均支持一键查询。
- **透明按钮设计**：按钮无背景、无边框，悬停变粉色，与评论区样式完美融合。
- **点击即显示**：点击“获取”后直接替换为 IP 属地（如“北京市”），无需弹窗。
- **手动刷新**：再次点击已显示 IP 的按钮可重新获取最新数据。
- **菜单命令**：
  - **手动扫描评论区**：手动触发按钮添加（适用于评论区滚动加载后）。
  - **获取 Access Key**：刷新登录凭证（遇到获取失败时使用）。

## 🚀 使用指南

### 基础使用
- **浏览个人主页**：自动显示 IP 属地，无需任何操作。
- **评论区查询 IP**：
  1. 滚动到评论区。
  2. 找到任意评论的 `IP属地：XX` 后方的 **“获取”** 按钮。
  3. 点击按钮，等待片刻（通常 1-2 秒），按钮文字会变为该用户的 IP 属地（如“北京市”）。
  4. 如需刷新，再次点击按钮即可重新获取。

### 菜单命令
点击浏览器右上角的 Tampermonkey 图标 → 悬停脚本名称，在子菜单中可选择：
- **🔄 手动扫描评论区**：如果评论区新增了评论但按钮未出现，可点击此命令手动添加。
- **【✅/❌ 已获取】获取 Access Key**：刷新登录凭证（若按钮显示“失败”时可尝试）。

## ⚠️ 注意事项

### 1. 必须登录 B 站
脚本需要调用 B 站 App 接口（`https://app.bilibili.com/x/v2/space`），因此必须使用你的登录凭证（`access_key`）。首次使用会弹出提示，确认后脚本会自动获取并存储。

### 2. 获取 Access Key 可能导致短暂掉线
首次获取 `access_key` 时，B 站可能会将当前会话踢下线（安全机制），重新登录即可。之后只需刷新页面即可继续使用。

### 3. 频繁请求可能触发风控
如果短时间内点击“获取”按钮过于频繁（例如连续点击几十次），B 站服务器可能返回风控错误（如 `-412`）。此时请：
- 等待 1-2 分钟后再试。
- 减少连续点击的频率。

### 4. 按钮显示“失败”怎么办？
- **可能原因**：`access_key` 过期、网络问题、该用户未设置主页 IP、请求频率过高。
- **解决**：
  1. 点击 Tampermonkey 菜单中的“获取 Access Key”刷新凭证。
  2. 等待几秒后再次点击按钮。
  3. 如果持续失败，请检查控制台错误信息。

### 5. 兼容性
- **浏览器**：Chrome、Edge、Firefox 等主流浏览器均可使用。
- **脚本管理器**：Tampermonkey、Violentmonkey 均支持。
- **B 站页面**：支持所有 `https://www.bilibili.com/*` 和 `https://space.bilibili.com/*` 页面。

## 🔍 常见问题

### Q：按钮为什么不显示？
- 评论区可能未加载完成，请滚动到评论区或点击“回复”按钮强制加载。
- 尝试在 Tampermonkey 菜单中点击“手动扫描评论区”。
- 检查是否已登录 B 站。

### Q：点击“获取”后一直显示“加载中...”？
- 请检查网络连接。
- 打开控制台（F12）查看是否有错误信息。
- 尝试刷新页面或重新获取 `access_key`。

### Q：个人主页 IP 不显示？
- 脚本仅在 `space.bilibili.com` 生效。
- 检查是否已登录 B 站。
- 尝试重新安装脚本。
