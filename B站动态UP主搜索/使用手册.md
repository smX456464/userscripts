# B站动态UP主搜索助手 使用手册

## 简介

本脚本为B站动态页面（`t.bilibili.com`）增加了一个便捷的UP主搜索入口，方便您快速查找并切换关注的UP主，同时支持全站用户搜索。脚本以油猴脚本（Tampermonkey）形式运行，具有以下亮点：

- **原位搜索**：在左侧UP主列表底部添加一个醒目的搜索项，点击即可弹出搜索窗口。
- **关注列表搜索**：实时提取左侧所有已加载的UP主，支持按名称或UID模糊匹配，点击结果自动定位并模拟点击，右侧动态流立即切换。
- **全站搜索**：调用B站官方搜索接口，输入关键词搜索全站用户，点击结果打开该用户个人空间（新标签页）。
- **视觉自适应**：弹窗背景颜色自动匹配页面主题，并根据明暗自动调整文字颜色，保证可读性。
- **操作流畅**：弹窗支持快捷键（Esc关闭），点击遮罩也可关闭，输入实时过滤，体验友好。

## 安装说明

1. **安装脚本管理器**  
   推荐使用 [Tampermonkey](https://www.tampermonkey.net/)（支持 Chrome、Edge、Firefox、Safari 等浏览器）。  
   其他兼容管理器如 Violentmonkey、Greasemonkey 也可。

2. **创建新脚本**  
   打开 Tampermonkey 管理面板，点击“新建脚本”，将脚本代码完整粘贴到编辑器中，保存即可。  
   脚本名称可自定义，例如“B站动态UP主搜索助手”。

3. **确认脚本已启用**  
   访问 `https://t.bilibili.com/`，脚本会自动运行。若页面已打开，请刷新一次。

> 注意：脚本仅匹配 `https://t.bilibili.com/` 域名，其他页面不会生效。

## 使用步骤

1. **定位搜索入口**  
   页面加载完成后，左侧“UP主”列表底部会出现一个粉色的圆形搜索图标，下方文字为“搜索”。  
   若列表较长，可能需要滚动到底部才能看到。

2. **打开搜索窗口**  
   点击该搜索项，弹出搜索窗口。窗口中央为搜索输入框，上方有模式切换按钮。

3. **选择搜索模式**  
   - **关注列表**（默认）：搜索当前左侧列表中已加载的UP主。  
   - **全站搜索**：搜索整个B站用户。

   点击按钮即可切换，切换后输入框会被清空，结果区域重置。

4. **输入关键词**  
   - 在关注列表模式下，支持模糊匹配UP主名称或UID（不区分大小写）。  
   - 在全站搜索模式下，输入任意关键词，脚本将实时请求B站搜索接口，显示匹配用户。

5. **点击结果**  
   - 关注列表模式：点击结果项，弹窗关闭，左侧列表自动滚动到对应UP主，高亮显示并模拟点击，右侧动态切换到该UP主动态。  
   - 全站搜索模式：点击结果项，将在新标签页打开该用户的B站个人空间。

6. **关闭弹窗**  
   - 点击右上角“×”按钮。  
   - 点击弹窗外的灰色遮罩区域。  
   - 按键盘 `Esc` 键。

## 功能详解

### 1. 搜索入口
- 位置：左侧UP主列表末尾，与列表项样式统一。
- 图标：粉色圆形背景，白色放大镜图标。
- 点击行为：打开搜索弹窗，并自动提取当前列表中的所有UP主信息。

### 2. 搜索窗口
- 窗口宽度约500px，高度自适应，最大高度为视口的80%。
- 背景色自动匹配页面主背景（如白色或深色模式），若无法获取则使用30%透明度白色。
- 根据背景亮度自动调整文字颜色（深色背景使用白色文字，浅色背景使用深色文字），保证对比度。

### 3. 模式切换
- **关注列表**：数据来源为左侧列表的DOM元素，支持模糊搜索名称和UID。结果中显示UP主头像、名称、UID。
- **全站搜索**：调用B站接口 `https://api.bilibili.com/x/web-interface/search/type?search_type=bili_user`，展示头像、昵称、UID、粉丝数。点击打开用户空间。
- 切换模式时，会清空输入框和结果，并更新标题（关注列表显示数量，全站显示“搜索全站用户”）。

### 4. 搜索结果交互
- 每条结果支持鼠标悬停高亮，点击触发对应动作。
- 关注列表点击后：滚动至目标项 → 添加2秒粉色边框高亮 → 模拟点击目标项（触发B站自身的动态切换逻辑）→ 关闭弹窗。
- 全站搜索点击后：直接 `window.open` 打开 `https://space.bilibili.com/{mid}`。

### 5. 自动修复已知问题
- 修复了从“全站搜索”切回“关注列表”时，不重新抓取左侧列表数据的bug。现在切换后会重新提取列表，保证数据最新。

## 注意事项与常见问题

### Q1：搜索入口没有出现？
- 请确保脚本已启用，并刷新页面。
- 可能是UP主列表尚未加载完全，脚本会等待列表出现后自动添加。若长时间未出现，请检查是否安装了其他类似脚本产生冲突。

### Q2：关注列表搜索结果不全？
- 脚本只会提取左侧列表中**已经加载**的UP主。如果关注人数很多，请手动向下滚动左侧列表加载更多，然后重新点击搜索项（或切换模式）以获取最新列表。
- 脚本本身不自动加载全部关注，以避免不必要的请求和性能影响。

### Q3：全站搜索失败或无结果？
- 全站搜索依赖B站接口，可能因网络、接口变动或风控导致失败。请检查网络连接，或稍后重试。
- 若接口返回错误，窗口内会显示提示信息。

### Q4：点击关注列表结果后，右侧动态没有变化？
- 可能是目标元素已被移除或B站前端逻辑变更。脚本尝试模拟点击，但若B站更新了内部实现，该操作可能失效。此时可尝试手动点击左侧列表对应项。

### Q5：弹窗文字看不清？
- 脚本已做自动对比度优化，若仍不满意，可以自行修改代码中的颜色常量。深色/浅色判断基于亮度计算，通常无需手动干预。

### Q6：可以自定义快捷键或样式吗？
- 可自行修改脚本中的 CSS 样式（如按钮颜色、弹窗宽度等）。主要样式集中在 `searchItem` 和 `modal` 的 `innerHTML` 中。
